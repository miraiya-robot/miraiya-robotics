SPECIFICATIONS

詳細スペック

UBTECH公式・originofbots・GA Roboticsより。ファクトチェック済（2026-05-29）。

身長
130cmは日本人中学生相当の背丈。大人の腰〜胸の高さ帯にアームの作業空間が集中するため、作業台・机・棚の下段ゾーンに適した研究環境で活躍する
130cm
重量
63kgは一般的な成人男性とほぼ同等の重量。研究室での搬入・設置には専用台車または2人以上での作業が必要
63kg
片腕可搬重量（伸展時）
UBTECH公式で「Single arm 1.5kg in extended state」と明記。腕を伸ばした状態での把持上限が1.5kg。originofbotsは「10 kgデッドリフト」「3 kg/手」と記載しているが公式未確認のため⚠️要注意
1.5kg⚠️デッドリフト10kgは公式未確認
モーター（サーボトルク）
高精度サーボのトルク範囲は4.5〜200 N·m。指先の繊細な力制御（4.5 N·m）から腰・脚部の高トルク関節（200 N·m）まで、41関節すべてに力フィードバック付きサーボを搭載
4.5〜200 N·m力フィードバック付きサーボ
最高歩行速度
公式値は歩行最高3 km/h（0.83 m/s）。originofbotsは「短距離スプリント10 km/h」と記載しているが公式サイトには記載なし。公式値の歩行3 km/hのみ信頼できる数値として使用
3 km/h⚠️10 km/hスプリントは公式未確認
段差・傾斜対応
最大傾斜20°（階段や坂道に相当）・最大段差15cm（一般的な段差・玄関段差相当）・不整地適応3cm。実験室・廊下・屋内環境の一般的な障害物に対応
傾斜20° / 段差15cm不整地3cm対応
使用環境
IP等級非公開。屋内研究・教育用途専用として設計。産業環境・屋外・水回りでの使用は想定されていない
屋内研究用IP等級非公開
全身自由度（DOF）
UBTECH公式で「41 high-performance servo joints」と明記。構成は脚6×2・腕7×2・手6×2・首3。すべての関節に力フィードバック付き高精度サーボを搭載
41 DOF脚6×2 / 腕7×2 / 手6×2 / 首3
アーム自由度
片腕7 DOFは肩・肘・手首の各関節に高い可動域を持ち、人間の腕の自然な動作パターンを再現。両腕14 DOFでの協調動作が可能
7 DOF × 2
ハンド自由度・形状
片手6 DOFの5本指構造。各指に独立した力センサーを内蔵しており、物体の材質・硬さに応じた把持力の繊細な制御が可能。研究用の触覚・把持実験に適している
6 DOF × 2（5指）各指力センサー内蔵
首自由度
首部3 DOFにより、仰角・水平回転・傾きの3軸方向への頭部移動が可能。カメラと連動した視線追跡・人間との自然なアイコンタクト動作を実現
3 DOF（首部）
後継モデルとの比較
Walker S（産業用・41 DOF・基本グリッパー）・Walker S2（産業用・52 DOF・5本指デクスタラスハンド）はいずれも産業用途。Walker Xは研究開発特化のロードマップで、SDK・シミュレーション環境が充実している点で差別化される
研究用ポジション産業用Walker S系とは異なる用途
連続稼働時間
公式値は複合動作条件で2時間。originofbotsは「1.5〜2時間」と若干異なる表記。実用場面では動作の複雑さにより1.5時間前後になる可能性があり、実験計画では1.5時間を基準とした方が安全
2時間複合動作条件 / 実稼働1.5〜2hの可能性
バッテリー仕様
リチウムバッテリー54.6V / 10Ah / 3.6kg。着脱可能なリムーバブルバッテリーパック設計。バッテリーを複数用意すれば手動で交換しながら連続実験が可能
54.6V / 10Ah3.6kg / リムーバブルパック
充電時間
2時間で満充電。稼働時間と充電時間が1:1のため、予備バッテリーを用意しない場合は交互運用（1台稼働・1台充電）が必要
2時間有線充電のみ
充電方式
有線充電のみ。自動帰巣・ワイヤレス充電には非対応。研究用途のため充電ステーションの自動化ニーズは限定的だが、長時間実験では充電管理の計画が必要
有線充電のみ自動帰巣なし
カメラ・ビジョン
デュアルRGBDカメラによる4眼ビジョンシステム。RGB（カラー映像）とDepth（距離情報）を左右で同時取得することで、より高精度なステレオ3D認識・奥行き推定が可能
4眼ビジョンデュアルRGBDカメラ
慣性センサー
IMU（慣性計測ユニット）を搭載。加速度・角速度をリアルタイムで計測し、歩行時の姿勢推定・バランス制御・転倒検知に使用。傾斜20°まで対応する安定した歩行の基盤
IMU搭載
測位・ナビ精度
測位精度10cm（通常ナビゲーション）・ナビゲーション精度20cm・精密測位1cm（特定条件下）。1cm精密測位は実験室での精密マニピュレーション研究で特に有用
測位10cm / 精密1cmナビ精度20cm
Wi-Fi
Wi-Fi 802.11 a/b/g/n（5GHz/2.4GHzデュアルバンド）。研究所内ネットワーク経由でのリモート操作・データ転送・ROSトピック通信に使用
Wi-Fi 802.11 a/b/g/n5G/2.4GHz デュアルバンド
有線通信
Gigabit Ethernet（RJ45）による高帯域有線接続と、EtherCATによるリアルタイム制御バスを標準搭載。EtherCATはモーション制御の業界標準プロトコルで、精密なリアルタイム関節制御研究に不可欠
Gigabit Ethernet + EtherCATUSB 3.0 / リアルタイム制御バス
演算ユニット
Intel Core i7-8665U（2019年製・1.9GHz）×2 + NVIDIA GT1030（384 CUDAコア・旧世代エントリーGPU）。AI推論・LLM実行には計算リソースが不足する点に注意。研究目的でのAI拡張には外部コンピュータとの連携推奨
i7-8665U ×2 + GT1030旧世代 · AI推論性能に制限あり
OS構成
Ubuntu Linux（メインOS）+ Linux RT Preempt（リアルタイムカーネル。μs単位の決定論的な制御ループに必要）+ ROS（Robot Operating System）+ Android（インターフェース用）の4層構成
Ubuntu + Linux RT PreemptROS + Android
ROS対応
ROS（Robot Operating System）を標準搭載。世界中の研究機関が蓄積したROSパッケージ・アルゴリズムをそのまま活用可能。既存の研究成果との統合・比較実験が容易
ROS標準搭載
二次開発SDK
メーカー提供の二次開発SDKにより、カスタムアプリケーション・制御アルゴリズムの実装が可能。研究機関・大学が独自のモーション・知覚・学習アルゴリズムを実機で検証できる
二次開発SDK提供
シミュレーション環境
URDF（ロボット記述フォーマット）とGazebo（物理シミュレータ）に対応。実機を使わずシミュレーション環境でアルゴリズムを検証→実機転移のワークフローが確立されており、実験コストと安全リスクを低減
URDF + Gazebo対応sim-to-real転移
EtherCATリアルタイム制御
EtherCAT（Ethernet Control Automation Technology）は産業用モーション制御の標準バスプロトコル。1ms以下の通信サイクルで41関節の同期制御が可能。精密な力制御・インピーダンス制御研究に適している
EtherCATリアルタイム関節同期制御
顔認識・音声・ジェスチャー
顔認識・音声コマンド・ジェスチャー認識を標準搭載。LLM統合はないが、人間との基本的なインタラクション機能を備えており、HRI（ヒューマンロボットインタラクション）研究のベースとして活用可能
顔認識 / 音声 / ジェスチャーLLM統合なし

KEY FEATURES

Walker X が際立つ6つの特長

研究開発プラットフォームとしての高い拡張性と、EtherCAT・ROS標準搭載による二次開発の容易さ。

✋
41 DOF × 6DoF/手 × 各指力センサー
脚6×2・腕7×2・手6×2・首3の合計41自由度。5本指の各指に独立した力センサーを内蔵し、把持力を繊細に制御。サーボトルク4.5〜200 N·mの広いレンジで、指先の繊細な操作から腰・脚部の高トルク動作まで対応する研究用マニピュレーション機構。
📡
EtherCAT標準搭載・リアルタイム関節制御
産業用モーション制御の標準バスプロトコルEtherCATを標準搭載。1ms以下の通信サイクルで41関節を同期制御し、精密な力制御・インピーダンス制御研究を実現。Linux RT Preemptリアルタイムカーネルと組み合わせた決定論的な制御ループが可能。
🐧
ROS対応・二次開発SDK・URDF+Gazebo
Ubuntu + ROS + Linux RT Preempt + Android の4層OS構成。メーカー提供の二次開発SDKとURDF/Gazebo対応でsim-to-realワークフローが確立。世界中の研究機関が蓄積したROSパッケージを活用した独自アルゴリズムの実機検証が容易。
📷
4眼デュアルRGBD × 精密測位1cm
デュアルRGBDカメラによる4眼ビジョンシステムで高精度なステレオ3D認識を実現。通常測位精度10cm・精密測位1cm（特定条件下）の高精度位置推定が可能で、精密なマニピュレーション実験のセットアップに対応。
🇯🇵
GA Robotics 日本代理店（2025年5月契約）
GA Robotics株式会社（東京）が2025年5月12日にUBTECHと代理店契約を締結。日本語サポートおよびGA Robotics経由でのWalker X取り扱い相談が可能。研究機関・大学への導入サポートも対応（取扱確認はGA Roboticsへ要問い合わせ）。
🏗
傾斜20°・段差15cm・不整地3cm対応
最大20°の傾斜・15cmの段差・3cmの不整地に対応し、実験室・廊下・施設内の一般的な障害物をクリア。4眼ビジョンを活用した障害物回避と組み合わせ、研究環境での自律移動を実現する十分な歩行能力を持つ。
IMPORTANT NOTES

導入前に確認すべき4つのポイント

2026年5月時点の公開情報をもとにした未来屋リサーチより。

🖥
Intel i7-8665U + NVIDIA GT1030は2019〜2021年の旧世代。現代的なAI推論・LLM実行には計算リソースが不足
i7-8665U（2019年製・Whiskey Lake世代）とGT1030（2017年製エントリーGPU・384 CUDAコア）は現在のAI推論ワークロードには著しく非力。リアルタイムのLLM推論・深層学習によるモーション生成・大規模な視覚認識モデルを実機上で走らせることは実質的に困難。AI研究への応用では外部GPUサーバとの連携（Wi-Fi / Gigabit Ethernet経由）が前提となる。
📅
2021年発売・ハードウェア陳腐化が進行。新規研究導入では最新世代機との比較検討を推奨
Walker Xは2021年発売で2026年時点で約5年が経過。競合の研究用ヒューマノイド（Unitree H1・G1、Fourier GR-1/GR-2等）は2023〜2025年発売で、より高性能なAIチップ・高速歩行・より強力なマニピュレーション能力を持つ。新規研究プラットフォームの選定では最新世代機との仕様比較を行った上で検討されたい。
💰
参考価格$75,000の公式確認不能。正確な価格はGA Robotics経由で要確認
ファクトチェックにより、レポートに記載の「$75,000（Robots International出典）」はRobots InternationalサイトのWalker Xページが「Add to Quote」形式で価格記載なしであることが判明。originofbotsの「$960,000」は明らかな誤記（桁が1桁多い）。正確な価格はGA Robotics株式会社への問い合わせで確認が必要。
🇯🇵
GA RoboticsのWalker X取扱が明示されていない。技適・PSEも未確認
GA RoboticsはUBTECHの日本代理店として2025年5月に契約を締結しているが、公式ページのメインラインナップはWalker C・E・S系が中心でWalker Xの明示的な取り扱い記載がない。研究機関向けの取り扱い可否は個別確認が必要。またWi-Fi搭載のため日本での使用には技適マーク取得が必要だが、取得状況が不明。
